# PlayerEx DC artwork

- `playerex-dc-icon.png`: transparent 256×256 icon for social profiles and mod listings. The in-game `assets/playerex/icon.png` is an identical copy.
- `playerex-dc-banner.png`: transparent 1200×400 banner for the README and marketplace descriptions.
- `button-*.png`: three matching 224×64 navigation buttons, with the same layout and platform accent colors.

The banner keeps the original brown/gold wordmark and book with its red bookmark. The clapperboard is removed, and the subtitle is shortened to DC. Use the same files across platforms rather than making separate variants.

Keep these filenames stable: the marketplace descriptions reference them on the repository's main branch. When replacing the icon, update both copies together.
